# Prompts para preparar `inputs/BLUEPRINT.md`

| Prompt | Cuándo usarlo | Salida esperada |
|---|---|---|
| `01-generate-blueprint-from-inputs.md` | Tienes un blueprint inicial, idea, PRD o notas, un ZIP de diseño/prototipo de apoyo y un template de blueprint. | Un `inputs/BLUEPRINT.md` completo para guardar en `inputs/BLUEPRINT.md`. |
| `02-audit-blueprint-before-bootstrap.md` | Ya generaste `inputs/BLUEPRINT.md` y quieres comprobar que alimenta bien el runtime. | Informe breve de bloqueantes y el `inputs/BLUEPRINT.md` corregido completo. |

El template de blueprint define la forma; el ZIP de diseño es apoyo visual: pantallas, rutas, layout, navegación, formularios, estados UI y copy. El blueprint manda para alcance, reglas, datos, permisos, estados, integraciones y verificación.
