# 00 - Blueprint runtime authority

This repository uses one human runtime authority and generated machine artifacts.

```text
inputs/BLUEPRINT.md
 -> orchestrator-state/compiled/orchestrator-input.json
 -> orchestrator-state/tasks/registry.json
 -> orchestrator-state/tasks/task-dag.json
 -> orchestrator-state/tasks/task-packs/<TASK_ID>.json|md
```

`inputs/BLUEPRINT.md` is arc42 plus fenced `yaml orchestrator` blocks. Prose explains; YAML blocks compile. The compiler must not infer executable behavior from prose.

## Authority order

1. Fenced `yaml orchestrator` blocks in `inputs/BLUEPRINT.md`.
2. `orchestrator-state/compiled/orchestrator-input.json` generated by `./scripts/compile-blueprint.sh`.
3. `orchestrator-state/tasks/registry.json` generated by `./scripts/bootstrap-registry.sh`.
4. `task-dag.json` and task packs generated by bootstrap.
5. Runtime evidence, handoffs, reports and ledger.

Generated artifacts are not edited by hand.

## Required machine-readable concerns

A complete blueprint declares:

- `kind: project`
- `kind: stack`
- `kind: auxiliary.arc42`
- `kind: building_blocks`
- `kind: logic.domain`
- `kind: logic.application`
- `kind: logic.journey`
- `kind: logic.permission`
- `kind: logic.state`
- `kind: logic.error`
- `kind: logic.integration`
- `kind: logic.ui`
- `kind: auxiliary.data`
- `kind: auxiliary.config`
- `kind: auxiliary.verification`
- `kind: auxiliary.adr`
- `kind: auxiliary.risks`
- `kind: auxiliary.glossary`
- `kind: auxiliary.external_refs`
- `kind: registry.slices`

Every machine-readable item must have a production-grade `description`, not only slices. Each slice must also have `title`, `dependency_rationale`, `depends_on_rationale` and `dependency_edges`. Descriptions are propagated into compiled input, registry, DAG, task packs, `resolved_dependencies` and `resolved_specs` so subagents receive human scope instead of bare IDs.

## Active input model

Do not create a second input model or parallel Markdown slash layer. Active execution is blueprint-first, explicit-DAG and skills runtime.

## Drift policy

If prose mentions an ID not declared in YAML, fix the blueprint. If official documentation changes a provider or Claude Code contract, record the discrepancy and reconcile the blueprint/adaptor. Do not patch generated JSON manually.
